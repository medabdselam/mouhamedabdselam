# mohamedabdselam.com

الموقع الشخصي لمحمد عبد السلام — مؤسّس ومدير شركة سند للمعدات الطبية، نواكشوط.

- **النطاق:** https://mohamedabdselam.com
- **الاستضافة:** GitHub Pages (نشر تلقائي عبر GitHub Actions عند كل push إلى `main`).
- **الصفحة الرئيسية:** `index.html` — صفحة واحدة، ثلاثية اللغة (عربي / فرنسي / إنجليزي) مع بوابة اختيار لغة تُحفظ في `localStorage`.

## البنية

الصفحة مبنية من قالب داخل `<template id="tpl">` يعرضه محرّك صغير مدمج في نفس الملف
(`sc-for` للتكرار، `sc-if` للشرط، `{{ }}` للقيم، و`style-hover` لحالات التمرير).
نصوص اللغات الثلاث في كائنات `AR` / `FR` / `EN` قرب نهاية الملف — لتعديل أي نص يكفي تعديلها.

المصدر الأصلي للتصميم: مشروع «تصميم موقع شخصي احترافي» على claude.ai/design،
وسكربت البناء في `C:\gti\sened-founder-site\build\build.ps1`.
