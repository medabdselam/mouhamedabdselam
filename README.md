## المحتوى

موقع ثابت (static) بثلاث لغات: العربية (افتراضية، RTL)، الفرنسية، الإنجليزية.

```
index.html          الصفحة كاملة — المحتوى العربي مكتوب في الـ HTML مباشرة
assets/css/site.css التنسيق وكل تأثيرات CSS
assets/js/site.js   الترجمة (fr/en) والتأثيرات التفاعلية
assets/brand/       الشعار والأيقونات
assets/, assets/tiles/  صور المنتجات (مرخّصة CC — انظر assets/images/CREDITS.md)
```

المحتوى العربي هو مصدر الحقيقة: نصوص الصفحة مكتوبة في `index.html` مع سمة
`data-i18n`، وملف `site.js` يحمل الترجمتين الفرنسية والإنجليزية بالمفاتيح نفسها.
عند إضافة نص جديد: أضف العنصر مع `data-i18n="key"` في HTML، ثم أضف `key` إلى
كائني `FR` و`EN` في `site.js`.

## الأمان

الموقع ثابت بالكامل: لا خادم، ولا قاعدة بيانات، ولا نماذج تُرسل بيانات —
فلا مجال لـ SQL injection أو تسريب بيانات زوّار.
إضافة إلى ذلك:

- **CSP صارمة** في `<meta>`: `default-src 'none'`، والسكربتات من `'self'` فقط.
  أي سكربت يُحقن في الصفحة لن يُنفَّذ، ولا يمكن إرسال بيانات إلى أي نطاق خارجي
  (`connect-src 'none'`) ولا إعادة توجيه الزائر عبر `<base>` (`base-uri 'none'`)
  أو عبر نموذج (`form-action 'none'`).
- **لا `innerHTML` ولا `eval`** في `site.js` — كل النصوص تُكتب بـ `textContent`،
  فلا يمكن تحويل أي نص إلى HTML أو كود.
- **حارس ضد التأطير (clickjacking)** في أول `site.js`، لأن `frame-ancestors`
  لا تعمل داخل `<meta>`.
- روابط `target="_blank"` كلها تحمل `rel="noopener noreferrer"`.
- اللغة المحفوظة في `localStorage` تُقارن بقائمة بيضاء قبل استعمالها.

في إعدادات المستودع على GitHub يجب أن يبقى **Enforce HTTPS** مفعّلًا.
